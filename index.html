Official rerelease of the server as ApolloRPG. A landmark update bringing a whole new dimension, five new bosses, three new weapon tiers, sweeping progression changes, and a full world reset from the previous Mining Sim Java server.

Added
  • New Dimension: Darklands
  • New Bosses: Gunmar The Black, Bular The Butcher, Angor Rot, Changeling, Infernax The Ancient
  • New Weapons: Daylight, Eclipse, Moonlight
  • New Armor Sets: Daylight Armour, Eclipse Armour, Moonlight Armour + New Vanity Sets
  • New Materials: Awakenings (Boss Lore), New Metals and Gemstones
  • New Accessories: Improved Crystals, New Crystal variants, Amulets
  • New Ores & Systems: Ancient Beings and associated content
Changed
  • Rerelease: Complete server reset and rebranding from Mining Sim Java to ApolloRPG
  • Rebalanced: Full progression rework + old boss rebalance

  • Reworked: Plot and Boss Summon system

v1.0.0 Launch
Origins
Mid 2025

The server originally launched as Mining Sim Java, an official port of the popular PS3 Minecraft world "Mining Sim". At launch it only contained core features: Animal Farm, Small Plots, Large Plots, and the Mine. Many features present in later versions were not yet implemented.
